Detecting Fraud Apps using Sentiment Analysis

Spot
fake reviews

Admins add applications, users comment on them, and every comment is scored Positive, Negative or Neutral and checked for repeat submissions from the same IP address — so the admin can decide whether an app is Genuine or Fraud.

Opinion mining

Each comment is scored Positive, Negative or Neutral, and apps are ranked by their average sentiment score.

Repeat-IP detection

Several comments for one app from the same IP address are flagged for the admin as a sign of fake reviews.

Detect Fraud Applications

Admins read ratings and comments for each app, then mark it Genuine or Fraud.
